# Оборонзаказ

Экономическая стратегия: вы — генеральный директор оборонно-промышленной корпорации и десять лет (январь 2026 — декабрь 2035) управляете 26 заводами. Надо исполнять гособоронзаказ, выигрывать экспортные тендеры и не обанкротиться. Деньги приходится тратить с расчётом: у каждого рубля есть цена, будь то кредит, простой цеха или неустойка.

Игра самостоятельная и с симулятором 558 АРЗ не связана: у неё свой код, данные, сборка и сохранения.

## Как запустить

Откройте `dist/index.html` в любом современном браузере. Это один файл, установка не нужна. Интернет нужен только для шрифтов, без него игра работает со стандартными.

Партия сохраняется автоматически каждый месяц. Есть ещё три ручных слота и текстовый код сохранения, чтобы перенести партию на другое устройство. Всё это в разделе «Меню и сохранения».

## Экономика

Модель держится на правилах, которые действуют в оборонке на самом деле:

- **Цена ГОЗ считается по затратам.** Заказчик признаёт нормативную себестоимость при загрузке мощностей 85% (материалы, ЭКБ, труд, амортизация, налог на имущество) плюс около 8,5% прибыли. Если завод загружен меньше, простой оплачиваете вы. Если себестоимость выросла, пересмотреть цену можно только торгом.
- **Отдельные счета ГОЗ.** Аванс по госконтракту лежит на счёте контракта. Тратить его можно только на этот контракт, на зарплату или кредит он не пойдёт.
- **Бухгалтерия.** Выручка признаётся в момент поставки, а не при получении аванса. Незавершённое производство и склад учитываются как запасы. Работают страховые взносы 30%, налог на прибыль 25% с переносом убытков (не больше половины базы), налог на имущество 2,2% и амортизация. Каждый месяц проверяется, что баланс сходится.
- **Деньги стоят денег.** Кредиты идут по ключевой ставке плюс спред, который зависит от вашего рейтинга. Есть льготные кредиты под ГОЗ, депозиты и дорогой овердрафт. Ключевую ставку ЦБ меняет на заседаниях по своему графику.
- **Валюта.** Расчёты с покупателями в долларах, евро, юанях, рупиях и дирхамах. Часть валютной выручки подлежит обязательной продаже. Рупии продаются с дисконтом 6%. Курсы колеблются, валютные остатки переоцениваются.
- **Экспорт** выгоднее ГОЗ в разы, но через спецэкспортёра уходит около 19% цены (комиссия, обучение, ЗИП). Партнёры требуют офсеты, госкредиты, страхование ЭКСАР, и есть риск санкций. Тендер разыгрывается по цене, технике, политике, офсету, условиям оплаты, срокам и репутации. Можно купить разведданные и узнать точные шансы.
- **Производство.** У каждой линии ограничены слоты, у завода ограничен штат. Цикл изготовления реальный: истребитель собирается год-полтора, С-500 больше двух лет, фрегат 22350 три с половиной года. Двигатели ставятся на финальной сборке, и их нехватка останавливает вертолёты и самолёты. Военная приёмка (ВП МО) возвращает брак на доработку.
- **Люди.** Можно менять зарплату, нанимать и увольнять. Новичкам нужно время на обучение. При низкой зарплате растут текучка и риск забастовки, при задержке зарплаты падает выработка.
- **Неустойка** за просрочку поставки составляет 1/300 ключевой ставки в день. Кроме того, падает доверие государства.
- **Доверие и KPI.** Каждый год правительство ставит четыре показателя: ГОЗ в срок, новый экспорт, доля гражданской продукции и чистый долг / EBITDA. Высокое доверие приносит больше заказов, господдержку НИОКР и субсидии на проекты. Если доверие падает до нуля, директора снимают. Если три месяца подряд нечем платить зарплату, это отставка. Минфин может выдать стабилизационный кредит, но не чаще раза в три года и ценой доверия.

## Как играть

1. **«Сводка»** показывает всё, что требует решения, и прогноз денег на полгода (пунктир).
2. **«Заказы».** Проекты контрактов ГОЗ можно принять, поторговаться о цене или сроке либо отклонить (за отказ снижается доверие). Если не ответить за два месяца, проект подпишут на условиях заказчика. Здесь же гражданские заказы и сервис техники за рубежом.
3. **«Производство».** Автоплан сам распределяет мощности по срокам. Можно вести линии вручную, ставить приоритеты и приостанавливать контракты.
4. **«Предприятия»** управляют зарплатой, штатом, ремонтом, модернизацией, жильём и учебными центрами.
5. **«НИОКР»** открывает новые изделия и снижает себестоимость, но деньги вкладываются заранее.
6. **«Экспорт»**: карта партнёров, тендеры, выставки и делегации.
7. **«Финансы»**: прибыли и убытки, движение денег, баланс, кредиты, валюта, макроэкономика.
8. Нажмите **«Завершить месяц»**. Кампания длится 120 месяцев, в конце выставляется итоговая оценка. После этого можно продолжить игру.

Несколько советов. Двигатели ВК-2500 — узкое место для всех вертолётов. Без сертификации SJ-100 и МС-21 «Аэрофлот» не получит самолёты, и пойдут неустойки. Не берите заказов больше, чем успеваете сделать: просрочка обходится дороже упущенной выручки.

Сложность выбирается при старте: «Лёгкий», «Обычный» или «Сложный». От неё зависят стартовые деньги и долг, доверие государства, маржа ГОЗ, санкции, цены ЭКБ, сила конкурентов и частота событий.

## Сборка из исходников

Нужен Node.js 18 или новее.

```bash
cd oboronzakaz
npm install
npm run build     # dist/index.html — готовая игра одним файлом
npm run watch     # пересборка при изменениях в dist/dev.html
npm test          # 3 партии ботом: баланс, NaN, итоговые оценки
node tools/simtest.mjs 2 --policy=passive   # игрок, который ничего не делает
node tools/simtest.mjs 1 --econ             # юнит-экономика изделий
npm run map       # пересобрать точечную карту мира (Natural Earth)
```

Структура:

```
src/data/   справочники: предприятия, изделия, страны, конкуренты, НИОКР, стартовый сценарий
src/sim/    движок: макроэкономика, финансы, производство, контракты, тендеры, НИОКР, события, ход
src/ui/     интерфейс на Preact: экраны, модальные окна, графики, карта
tools/      сборка (esbuild), генератор карты, симуляционные тесты
```

## Оговорка

Названия предприятий, изделий, стран и иностранных образцов настоящие. Цены, себестоимость, численность персонала, мощности и сроки — оценки по открытым источникам, подобранные для игрового баланса. Контракты, события и решения в игре вымышлены и не описывают реальную деятельность упомянутых организаций.
